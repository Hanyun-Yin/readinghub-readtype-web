# readinghub · 阅读人格测试

纯静态小工具站：12 题 × 4 轴 = 16 种阅读人格（读书版 MBTI），纯离线 Canvas 出结果卡。

- 面向小红书受众的病毒传播小工具，结果卡带 readinghub 品牌水印
- 可部署到 CloudBase（境内可达）或 Vercel / GitHub Pages（海外）

## 本地预览

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 部署

- **CloudBase（境内）**：`bash deploy-cloudbase.sh`
- **Vercel（海外）**：`bash deploy.sh`
- **GitHub Pages（海外）**：Settings → Pages → Deploy from a branch → main / (root)
